Last Mile Out

This fictional evacuation drill shows which households lose a viable assignment when roads, shelter access, and vehicles change. The same calculated result drives the map, household cards, and copyable report.

Three stops in the code

  1. src/scenario.js — baseScenario: find the fictional bridge, households, shelters, and vehicle limits.
  2. src/planner.js — findRoute and planScenario: see how the app rejects closed roads and finds an assignment within capacity.
  3. src/app.js — the bridge click handler and render: follow the input back to the visible result. src/report.js turns that result into the copyable text.

This is a reference route through the finished app; it does not imply a guided code tour was completed.

To change this, start here

  • Change a household or road in src/scenario.js.
  • Change assignment rules or uncovered reasons in src/planner.js, then run npm test.
  • Change the explanation below the switches in src/app.js.
  • Change the meeting summary in src/report.js.
  • Change colors and responsive layout in styles.css.

A practice to reuse

The requirement “show who is left out” became a concrete sequence: close the bridge, identify Nia’s missing route, add shelter access, then identify Ayo’s missing vehicle. tests/planner.test.js checks each step. Defining a visible sequence before building helped catch the unclear handoff; the explanation was revised from learner feedback. Use the same approach for another project: choose one action, write down the expected visible result, and verify it.

Run it again

From the project folder, run npm start and open http://localhost:4174. Run npm test to check the planner and report. This guide describes source commit 151596a and may need an update if the app changes.
